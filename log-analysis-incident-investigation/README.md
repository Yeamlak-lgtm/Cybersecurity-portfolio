## Log Analysis & Incident Investigation
Project Overview
This project demonstrated how Python can be used to analyze authentication logs, identify suspicious activity, and investigate potential cybersecurity incidents.
The objective is to simulate the work of a cybersecurity analyst by examining login activity, identifying abnormal patterns, documenting findings, and recommending actions to improve organizational security.
